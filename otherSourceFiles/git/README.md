The git-sh-prompt is to enable the git information on the prompt

We can find git-sh-prompt and git-prompt in ubuntu with "dpkg -L git|grep prompt" if we install the git.
We can also fins the "git-sh-prompt" be named as "git-prompt.sh" in the git repo.
reference: https://github.com/git/git/blob/master/contrib/completion/git-prompt.sh
